# Claude 远程（安卓端）使用说明

本文档对应 `C:\0WINBOT\ClaudeCodeAndroid-Project-Development\ClaudeCodeAndroid` 项目：安卓 App 通过本机 WINBOT 的桥接服务，
远程驱动本机安装的 Claude Code（模型走 Ollama `gemma4:12b`）。

## 一、安装 APK

APK 位置：`C:\0WINBOT\ClaudeCodeAndroid-Project-Development\ClaudeCodeAndroid\claudecode\build\outputs\apk\debug\claudecode-debug.apk`

方式一（USB 连接手机）：

```powershell
$adb = "C:\0WINBOT\AndroidStudio\AndroidSDK\platform-tools\adb.exe"
& $adb install -r "C:\0WINBOT\ClaudeCodeAndroid-Project-Development\ClaudeCodeAndroid\claudecode\build\outputs\apk\debug\claudecode-debug.apk"
```

方式二：把 APK 传到手机（微信/网盘/数据线均可）后手动安装，需允许“未知来源安装”。

要求：Android 7.0（API 24）及以上。

## 二、首次配置

1. 手机与 WINBOT 在**同一局域网**（`192.168.123.0/24`）。
2. 打开 App → 底部「设置」：
   - 桥接服务地址：`http://192.168.123.202:8787`
   - 访问令牌：见 `C:\0WINBOT\ClaudeCodeAndroid-Project-Development\ClaudeCodeAndroid\bridge\config.json` 的 `token` 字段
   - 默认工作目录：`C:\0WINBOT`
3. 点「测试连接」，出现“连接成功 · 模型 gemma4:12b · claude.exe 就绪”即完成。

> token 是随机生成的 48 位字符串，等同于本机的执行授权，不要截图外传。

## 三、日常使用

1. 列表页「新建会话」→ 填标题与工作目录（必须在白名单 `C:\0WINBOT`、`C:\Users\ZhanGSKen` 内）。
2. 进入会话后直接下达指令，例如：
   - “看下 Ollama模型训练 目录里的 README，总结当前 GPU 配置”
   - “把 reports 下所有 md 的标题列成一张表”
3. Claude 的每一段文字会**逐字流式**出现在白色气泡里；黄色卡片是工具调用与返回。
4. **写文件、跑命令会弹审批窗**：
   - 「允许」：本次放行
   - 「本会话总是允许」：该工具在本会话内不再问
   - 「拒绝」：Claude 收到拒绝并改变做法
5. 「中断」按钮可随时打断正在执行的一轮。
6. 断网或切后台回来后，App 会自动重连并从断点续播，不会漏事件。

## 四、桥接服务管理

服务已注册为计划任务 `ClaudeBridge`（登录自启、隐藏窗口）：

```powershell
Start-ScheduledTask -TaskName ClaudeBridge     # 启动
Stop-ScheduledTask  -TaskName ClaudeBridge     # 停止
Get-ScheduledTask   -TaskName ClaudeBridge     # 查看状态
```

重新注册 / 卸载：

```powershell
powershell -ExecutionPolicy Bypass -File C:\0WINBOT\ClaudeCodeAndroid-Project-Development\ClaudeCodeAndroid\bridge\scripts\register-task.ps1
powershell -ExecutionPolicy Bypass -File C:\0WINBOT\ClaudeCodeAndroid-Project-Development\ClaudeCodeAndroid\bridge\scripts\unregister-task.ps1
```

健康检查：

```powershell
Invoke-RestMethod http://127.0.0.1:8787/api/ping
```

日志：`C:\0WINBOT\ClaudeCodeAndroid-Project-Development\ClaudeCodeAndroid\bridge\data\bridge.log`

### 防火墙

手机访问需要放行 TCP 8787（仅内网网段）：

```powershell
# 需管理员权限
powershell -ExecutionPolicy Bypass -File C:\0WINBOT\ClaudeCodeAndroid-Project-Development\ClaudeCodeAndroid\configure-bridge-firewall.ps1
```

当前已创建规则 `Claude Bridge - Allow 192.168.123.0/24`。

## 五、外网访问（可选）

不建议把 8787 直接映射到公网。推荐在 STUDIO（192.168.123.222）的 openresty 上加一个 HTTPS 反代站，
例如 `https://claude.studio.winboll/`，要点：

```nginx
location / {
    proxy_pass http://192.168.123.202:8787;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    # SSE 必须关闭缓冲，否则流式输出会被攒起来
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 600s;
    proxy_send_timeout 600s;
    add_header X-Accel-Buffering no;
}
```

App 端把地址改成 `https://claude.studio.winboll` 即可（HTTPS 不需要再单独配明文放行）。

## 六、常见问题

| 现象 | 排查 |
|---|---|
| 列表页显示“连接失败” | 服务是否在跑（`Get-ScheduledTask ClaudeBridge`）、token 是否正确、手机是否同网段 |
| 显示“连接被拒绝（HTTP 401）” | token 与 `config.json` 不一致 |
| 一直“连接中…” | 防火墙未放行 8787，或走了外网但反代未关 `proxy_buffering` |
| 发送后无响应 | 模型在加载（首次约 5–20 秒）；看 `bridge\data\bridge.log` |
| 提示“会话上一轮仍在执行” | 等这轮结束或点「中断」 |
| 审批弹窗一直不来 | 该工具被 Claude Code 判定为只读自动放行；写操作才会弹 |

## 七、回滚

1. 手机卸载「Claude 远程」。
2. `unregister-task.ps1` 删除计划任务。
3. 删除目录 `C:\0WINBOT\ClaudeCodeAndroid-Project-Development\ClaudeCodeAndroid`（含桥接数据与 token）。
4. （可选）删除防火墙规则：`Remove-NetFirewallRule -DisplayName "Claude Bridge - Allow 192.168.123.0/24"`。
